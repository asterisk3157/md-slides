## アニメーション拡張

### 1. 見出し（ヘッダー）の既定フェード
- 各スライドの見出しブロックを、既定で **左→右フェードイン**（不透明度＋左からのスライド）で表示する。
- 現状は全ブロック共通の「左→右ワイプ（クリック送り）」。見出しはフェード系にして掴みを良くする。
- pptx: 見出しブロックに Fade/FlyIn(fromLeft) 系の entr アニメ。SVG プレビュー: CSS で軽くプレビュー。

### 2. 編集バーに方向アニメ（十字4方向の矢印）
- fmtbar に十字配置の4方向矢印（↑↓←→）ボタンを表示。
- ブロックを選択した状態で矢印を押すと、そのブロックに **「その方向から手前（視点側）に向かって文字が浮かび上がる」** 登場アニメを割り当てる。
  - 例: ←を押す→左から入って手前にせり出す。方向＋奥行き（zoom/grow）を合成した entr アニメ。
- ブロック単位の per-block アニメ設定として frontmatter（overrides 相当）に保存し、pptx の per-shape アニメに反映。
- SVG プレビューでも方向のヒント表示（再生 or アイコン）。
