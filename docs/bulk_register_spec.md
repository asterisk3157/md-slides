# 連続登録モード（バルク登録）仕様

ユーザー要望: 1文字ずつクリックして手書きするのは非効率。「足りていない文字を自動で次々表示して、書く→次→書く→次」のフロー。

## エントリ

トップ画面（`index.html`）の右上に **「📝 連続登録モード」** ボタンを追加。

## セット選択モーダル

ボタンクリックでモーダルを開く。

### 選択項目
- **プリセット文字セット**（複数選択可）
  - ひらがな（46字、`あ` 〜 `ん`、濁点・半濁点別途）
  - 濁点・半濁点 / 拗音（が〜ぽ、ゃゅょっ）
  - カタカナ（46字）
  - 数字（0〜9）
  - 英字（a〜z, A〜Z）
  - 数学記号（+ − × ÷ = ( ) [ ] { } . , < > ≦ ≧ ≠ ≈ ± ∞ √ ∫ ∑ π θ α β γ）
  - 区切り（・「」、。！？）
  - **お手本に出現した文字**（後で抽出機能を作ったら有効化）
- **カスタム文字列**: テキストエリアに任意文字列を貼り付け、ユニーク化して使う
- **目標バリエーション数**: デフォルト 3（DBで `count(*) < target` の文字を未達成とみなす）

### 開始ボタン
クリックで `/bulk.html?set=<ids>&target=<n>&custom=<urlencoded>` へ遷移。

## 連続登録画面 (`bulk.html`)

### 上部
- 進捗バー: `登録済み 12/46 文字達成（未達成 34 文字）`
- ステータス: `現在: 「あ」（2/3 バリエーション登録済み）`
- 「やめる」ボタン → トップへ戻る

### 中央
- 手書きパッド（既存 `char.html` のものをコンポーネント化）
- 対象文字を薄く重ねる（ガイド）

### ボタン
| ボタン | キーボード | 動作 |
|---|---|---|
| 💾 登録して次へ | Enter | 現在の手書きを POST、`count` が `target` 未満ならその文字に留まる、達成済みなら次の未達成文字へ |
| → スキップ | → | 保存せず次の文字へ |
| ← 戻る | ← | 前の文字に戻る（既存バリエーション再確認用） |
| ↻ やり直し | u | 直前のストロークを取消 |
| 🗑 全消去 | c | 手書きエリアをクリア |
| ▶ プレビュー | p | 描いた順を200ms間隔で再生 |

### 全達成時
- 「🎉 完了！全 46 文字が目標 3 バリエーションに到達」
- 「トップへ戻る」「もう一周（target+1 にする）」ボタン

## 内部処理

### 未達成リスト取得
```
GET /api/bulk/missing?chars=あいうえお...&target=3
→ {"missing": ["え", "お", "か", ...]}  // 上記から count<3 のものだけ
```

### 順序
- ユニコード順（既存仕様と整合）
- 一旦リストを取得したら、その順で進む（途中で他の人が登録しても順序は変えない）

### 自動進行
- 「登録して次へ」を押す → POST 成功 → カウント再取得 → 目標到達なら次へ、未達成なら同じ文字（次のバリエーションを書く）
- 同じ文字で連続書きすると右側に「直前に書いたバリエーション」のサムネが薄く表示され、似すぎないかチェックできる

## 実装ファイル

```
dict_app/
├── public/
│   ├── bulk.html                # 連続登録画面
│   └── js/
│       ├── bulk.js              # ロジック
│       └── stroke_pad.js        # 手書きパッドを共通化（char.htmlからも使う）
└── functions/api/
    └── bulk/
        └── missing.ts           # GET /api/bulk/missing
```

`index.html` と `char.html` には連続登録モードボタンを追加。

## キーポイント

- 目標バリエーション数は **動的に変更可能**（最初3で開始 → 全達成 → 4にして再度回す、など、品質を段階的に上げられる）
- 「お手本に出現した文字」セットは将来お手本抽出機能が実装されたら有効化（今は disabled）
- API は既存の `/api/chars` と `/api/chars/:c/variants` をそのまま使い、追加は `/api/bulk/missing` だけ
