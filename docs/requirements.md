# Tegaki Slides 要件定義

> 本書は 2026-05 の要件定義セッションの確定事項。設計判断の根拠は
> [design_decisions.md](design_decisions.md)、記法は [md_spec.md](md_spec.md) を参照。

## 0. 北極星（製品の芯）

- **「MD から爆速でスライドの骨組みを作る」**。最初から整った出力。
- **編集機はラストワンマイル（脇役）**。手で動かす回数＝出力が悪かったサイン。
- **MD は"中間表現"であって"オーサリング言語"ではない**。人が直接書くのは power user のみ。
  一般ユーザーの入口は **LLM 生成 ＋ WYSIWYG 編集**。
- 新機能の物差し：「MD→骨組みを速く・綺麗にするか？」=やる／「PowerPoint に似せるだけ？」=やらない。

## 1. ターゲット / ペルソナ

- **当面の狙い：無料で教員に広く配布（非商用）。STEM 中心。**「多くの教員がすぐ使える」がゴール。
- ペルソナ
  - **P0 power user（作者本人）**：MD 直書き。手書きも使う。
  - **P1 数学/STEM 教員**：数式・増減表が要る。MD は書かない → LLM＋編集。
  - **P1' 化学教員**：分子式・反応式が要る（化学記法 `\ce{}`）。同上。
  - **P2 一般教員（非STEM）**：箇条書き中心。とにかく簡単・すぐ。

## 2. 提供価値・差別化（堀）

競合（Gamma/Tome/PowerPoint Copilot/イルシル）は **汎用・英語中心・SaaS 囲い込み・数式/板書が弱い**。空き地は：

1. **教育記法の深さ**（**数学**：数式・増減表・矢印 ／ **化学**：分子式・反応式 `\ce{}`）＝丁寧な再現が面倒で参入障壁 ◎【主軸】
2. **本物の編集可能 pptx（ロックインなし）**＝既存ワークフロー温存・学校で強い ◎【主軸】
3. 本人の手書き＝唯一無二の情緒フック。ただし登録コスト＝採用障壁 △【任意の上位体験に降格】

→ 堀は **①×② の束**。手書きは「後から本人化する任意機能」。

## 3. ビジネス / 配布

- **非商用・無料**。課金・アカウント・組織管理機能は**作らない**。
- 最優先は **"すぐ使える・ログイン障壁を下げる"**。
- （将来もし収益化するなら）フックは"生成そのもの"でなく **本人化・テーマ・共有/ホスティング** に寄せる。

## 4. オーサリング（入口は3層）

1. **テンプレ/サンプルから開始**（ゼロから書かせない）
2. **LLM が下書き MD 生成**（爆速エンジン）
3. **WYSIWYG 編集**（実装済みツールバー＝非技術教員の主要な調整面）

- **LLM 統合方式：外部コピペを軸**（記法スペックを各自の ChatGPT/Claude に貼る → MD を戻す）。
  - 内蔵 API 課金は**却下**（無料配布と両立しない・維持者コスト）。BYOK は将来の任意。
  - UX：「プロンプト＋スペックをワンクリックコピー」「生成結果を貼る欄」を磨く。

## 5. 描画モード ＋ アニメーション

**エンジン共通／描画プロバイダ差し替え**。

| モード | 用途 | 文字 | 既定アニメ |
|---|---|---|---|
| **テキスト（既定・中心）** | 一般配布 #31 | **フォント**（地の文も数式・化学式も全部フォント。手書き不使用） | **左→右ワイプ**（ON/OFF 可） |
| **手書き（任意・上位）** | 本人化 | **インク**（全部手書きグリフ） | 手書き再生（drawProgress、ON/OFF 可） |

- **モードは排他**：テキスト＝100%フォント（インク/辞書を一切使わない）／手書き＝100%インク。
- **レイアウト・サイズ・配置エンジンは共通**（手書き版の配置ロジックを流用）。違うのは「各グリフをインクで描くかフォントで描くか」だけ。
  - アーキ：layout は「文字 C を (x,y) にサイズ s で置く」という**抽象グリフ配置**を出力 → renderer がインク or フォントに振り分け（描画プロバイダ差し替え）。
  - 数式・化学式も同じ：配置(分数/添字/積分等)は共通エンジン、描画だけフォント文字＋手続き線(分数バー等)。
- **テキストモードは辞書を一切使わない＝真のコールドスタートゼロ**。手書きは完全に任意の別モード。
- **アニメは ON/OFF トグル(#30)**：テキスト既定＝ワイプ左→右、手書き＝描画再生。
- **既定フォント＝フリー（推奨 Noto Sans JP）**。**ツールバーのフォント選択（PowerPoint風ドロップダウン）＋ frontmatter `font:`** で変更可。
  - 留意：数式記号(∫√Σ∂等)のフォントカバレッジを確認（不足時は数式対応フォントにフォールバック）。

## 6. 機能要件

- 入力：MD（フロントマター＋本文）。テンプレ/サンプル選択。.md ドロップ。
- レンダリング：MD → レイアウト → 配置 → プレビュー(SVG) ＋ pptx 出力（現物 .pptx）。
- 記法：見出し/小見出し/箇条/段落/メモ`>`/表/増減表/インライン・ブロック数式/色/太字（既存）。
- **化学記法 `\ce{...}`（mhchem 風）**：L1 分子式・イオン式（H₂SO₄, SO₄²⁻, Ca²⁺）／L2 反応式（係数・→・⇌・矢印上下の条件・状態 (s)(l)(g)(aq)）。既存の数式配置エンジン（添字/上付き/矢印アンカー）に流す。L3 構造式（簡易ChemDraw）は将来。
- フォントサイズ：pt の役割別固定プリセット（heading/subheading/body/note）。はみ出しは赤警告。
- 編集：ブロック移動/リサイズ（Shift スナップ）、ブロック・文字単位の 太字/色（パレット）/サイズ。
- 描画モード切替：テキスト⇔手書き。アニメ ON/OFF。
- 不足文字（手書きモードのみ）：QR 登録導線。**テキストモードでは不要**。
- 出力：pptx ダウンロード（クライアント側生成）。

## 7. 非機能要件

- **生成はクライアント側完結**（Cloudflare 無料・サーバコスト最小）。
- **配布のためアクセス障壁を下げる**（→ §10 未決：公開範囲）。
- プライバシー：手書き辞書は登録者のもの。共有 D1 の汚染対策（→ §10 未決）。
- 出力は **ロックインのない現物 .pptx**。
- Python(真実) ↔ JS(移植) は **byte 一致**を維持。

## 8. アーキテクチャ

```
MD → parse → layout(役割別サイズ/フロー) → 配置(placed) → [描画プロバイダ] → 出力
                                                          ├─ text     : pptx ネイティブテキスト + フォント
                                                          └─ handwriting: インク(InkML) + 手書きアニメ
```

- 描画プロバイダをインターフェース化（glyph 供給＝フォント輪郭 / 手書き dict）。
- overrides（空間・色・太字）は両モード共通の後処理層。

## 9. ロードマップ（優先順）

1. **#31 テキストモード（フリーフォント）＋ 数式/化学のテキスト描画方式確定（未決2＝ハイブリッド）** ← コールドスタート解消・配布の要【最優先】
2. **#30 アニメ ON/OFF トグル**（テキスト既定＝左→右ワイプ／手書き＝描画再生）
3. **化学記法 `\ce{}` L1+L2**（分子式・反応式）＝化学教員ピッチの主力
4. **レイアウト知能**（2段組み・縦中央寄せ・テーブル幅フィット等＝"デフォルトで綺麗"）
5. **テンプレ / LLM 入口の UX 磨き**
6. （将来）化学構造式 L3（簡易ChemDraw）／ 手書きモードの任意アップグレード整備

## 10. 未決事項（要・追加判断）

- **配布時のアクセス/認証 ＋ 辞書の共有/汚染**（連動）：生成と"作者の既定手書き辞書の読み取り"は公開可。ただし辞書への**書き込み(登録)は保護**し、共有既定辞書を汚さない（個人の手書き登録は分離 or ローカル）。広く配布する段で確定。
- ~~テキストモードの数式・化学式描画~~ → **確定：テキストモードは全部フォント**（数式・化学式も含め手書き/インク不使用。配置は共通レイアウトを流用）。§5 参照。
