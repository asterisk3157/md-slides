# md-slides — UI デザイン・ブリーフ（共通）

> このファイル（brief.md）＋ `styles.md` の **1スタイル分** を Claude Design に貼って使う。
> 3スタイル（Microsoft / Material / Liquid Glass）を別々に走らせて見比べる。
> 現行実装の実物は `public/preview.html`（HTML＋インラインCSS）／`public/styles.css`。これを「再スタイル」する。

## プロダクト概要
**md-slides**：Markdown を打つと整ったスライド（編集可能な .pptx）が出る、教員向け無料Webアプリ（STEM中心）。
- 完全クライアント完結（静的配信）。ログイン不要。
- 「MD→骨組みを爆速で・最初から整って」が芯。**編集機はラストワンマイル（脇役）**。
- 文字・数式・化学式は全部フォント描画。プレビューは SVG、出力は ネイティブテキスト pptx。

## 再デザインする画面＝「作成」ページ（`/preview`）
1画面のエディタ。領域は次の通り：

- **アプリバー（最上部）**：ロゴ（製品名は未定・ワードマーク差し替え可）／主要アクション（**pptx ダウンロード**＝主ボタン、位置を保存、リセット系）。
- **書式ツールバー（fmtbar）**：選択中のブロック/文字に効く。太字 B ／色（パレット）／サイズ ± ／フォント選択 ／**登場方向（← ↑ ↓ → ＋ なし）**。
- **MD エディタ（左ペイン）**：等幅テキストエリア。縦リサイズはしない（スクロールのみ）。
- **プレビュー（右ペイン）**：スライド群。**現状は縦に長く積まれていて良くない**（§レイアウト目標参照）。
- **AI記法コピー**：LLM 用の記法ルールをコピーする textarea＋ボタン（現状ページ下部で配置が浮いている → §レイアウト目標）。
- **設定（新設したい）**：既定フォント／アニメ ON-OFF／全リセット／AI記法コピー をまとめる場所（ギア等）。

## レイアウト目標（今回の主眼・ここを良くしたい）
1. **スライドを「右に縦長バー」で出さない**。**16:9 のメインプレビュー1枚を大きく中央に**＋**サムネイル/フィルムストリップ（横スクロール）でスライド切替**、が理想。PowerPoint/Keynote/Google スライドのような「1枚編集＋一覧ナビ」。画面（16:9 想定）に収まるのがベスト。
2. **設定パネル/タブ**を新設し、そこへ：**既定フォント・アニメ ON/OFF・全リセット・AI記法コピー** を集約（散らからないように）。
3. **編集ヒント**（「クリックで選択→ドラッグ移動／角でリサイズ／Shiftで吸着」等）は常時出さず、**編集時だけ控えめに**（トースト/インライン小文字など、邪魔にならない場所）。
4. **アクティブスライドの可視化**：表示中/選択中スライドを淡い強調（薄い青背景など）。サムネと本文の対応がわかるように。
5. 全体を **「Webページ」でなく「アプリ」** に見せる（余白・階層・密度をアプリ的に）。

## 必ず守る制約（重要：JS が動き続けるための DOM 契約）
既存 JS（`public/js/preview.js`）が次の **要素 id / クラス / 構造** に依存している。**id・主要クラスはそのまま残す**（位置・見た目・入れ物は自由に変えてよい）。

必須 id（同名で存在させる）:
- 入力/プレビュー: `md`(textarea), `slides`(プレビュー差し込み先), `status`
- ツールバー: `fmtbar`, `fmtBold`, `fmtColorBtn`, `fmtColorChip`, `fmtColorPop`, `cpStd`, `cpGray`, `fmtColor`, `fmtClsClear`, `fmtRole`, `fmtSizeVal`, `fmtSizeUp`, `fmtSizeDown`, `fontSel`(select), `animLeft`,`animUp`,`animDown`,`animRight`（＋追加予定 `animNone`）
- アクション: `dl`(pptxダウンロード), `save`, `resetSel`, `resetAll`
- AI記法: `llmSpec`(textarea), `copyLlm`
- （レガシー・テキストモードでは非表示で可）: `missingBar`, `qrOverlay`, `qrCode`, `qrCount`, `qrMissingList`, `qrUrl`, `qrDone`, `qrSkip`

必須クラス/構造（プレビューSVGは JS が生成。CSS で見た目だけ整える）:
- `#slides` の中に各スライド `.slide`（＋`.num`見出し）。その中に `<svg>`。
- スライド内 SVG: ブロック `.blk`／当たり判定 `.bhit`／要素 `.el`／`.ehit`／選択枠 `.sel-rect`/`.handle-rect`。これらの hover/charmode 用 CSS は流用。
- カラーパレットのスウォッチ `.sw`。

> JS の配線は実装者（開発側）が後で行う。デザインは **HTML 骨格＋CSS** を、上記 id を保ったまま提供してほしい。新コントロール（設定パネル、サムネイル等）は新 id/クラスを付けてOK（こちらで結線する）。

## 成果物（Claude Design への依頼形式）
- **単一の自己完結 HTML（インラインCSS可）** で、上記レイアウト目標を満たす「作成」ページのUIを提示。
- スライド領域には **ダミーのスライド（16:9 の白いカード）数枚** とサムネイルを置いて、レイアウトが伝わるようにする。
- ツールバー・設定パネル・アプリバーの **実際のコントロール**（ボタン/セレクト/パレット）を、指定の id を付けて配置。
- レスポンシブでなくてよい（デスクトップ前提、16:9 想定）。ダーク/ライトは各スタイルの流儀で。
- アイコンは各デザイン言語純正の雰囲気で（外部アイコンフォント不可なら inline SVG）。

## サンプル文脈（プレビューに入る内容のイメージ）
見出し・箇条書き・インライン数式 $a^2+b^2=c^2$・分数・積分 ∫・総和 Σ・増減表・化学式 H₂SO₄ など。教材スライド。
