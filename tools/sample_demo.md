# きほんのきほん

- ふつうの ぶんしょう です
- **ふとじ** も つかえます
- すうしき $a + b = c$ も インラインで OK
- **ふとじ** と $x^2$ の **ミックス** も OK

---

# べきと そえじ

- $x^2 + y^2 = r^2$
- $a_n = a_1 + (n - 1) d$
- $E = m c^2$
- $f(x) = x^3 - 3 x + 1$

---

# ぶんすう と るーと

- $\frac{1}{2} + \frac{1}{3} = \frac{5}{6}$
- $\frac{a + b}{c - d}$
- $\sqrt{2} \approx 1.41$
- $\sqrt[3]{8} = 2$

---

# せきぶん と そうわ

- $\int_0^1 x^2 dx = \frac{1}{3}$
- $\sum_{n = 1}^{N} n = \frac{N (N + 1)}{2}$
- $\int_a^b f(x) dx$
- $\sum_{k = 0}^{\infty} \frac{1}{k!}$

---

# かんすう と きょくげん

- $\sin \theta + \cos \theta$
- $\log_{10} 100 = 2$
- $\lim_{x \to 0} \frac{\sin x}{x} = 1$
- $\tan \theta = \frac{\sin \theta}{\cos \theta}$

---

# ぎりしゃ と えんざんし

- $\alpha + \beta = \gamma$
- $\pi \approx 3.14$, $\theta = \frac{\pi}{6}$
- $a \times b \div c \pm d$
- $x \neq y$, $a \leq b$, $c \geq d$

---

# やじるし と べくとる

- $A \to B \Rightarrow C$
- $\vec{a} + \vec{b} = \vec{c}$
- $\vec{v} = (v_1, v_2, v_3)$
- $|\vec{x}| = \sqrt{x_1^2 + x_2^2}$

---

# プライム と ふくごう

- $f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$
- $f''(x) > 0$ なら **したに とつ**
- せってんは $f'(t) (x - t) + f(t)$
- **けつろん**: $f'(x) = 0$ の かいすう
