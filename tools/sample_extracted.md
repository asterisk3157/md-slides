# スライド1 せっせんの本数

- **だい8かい せっせんの本数** … 「じょうけんを みたす せっせん」を かぞえる
  - まず せっせんを じゅんび
  - せってん が ないと しきが たてられない

**[れい]** $f(x) = x^3 - 9x^2 + 15x - 7$ とする。

- $y = f(x)$ の $(t,\ f(t))$ における せっせんの ほうていしきは $y = f'(t)(x - t) + f(t)$
- $f'(x) = 3x^2 - 18x + 15$ より、せっせんは

$$
y = (3t^2 - 18t + 15)(x - t) + (t^3 - 9t^2 + 15t - 7)
$$

(* 下線注釈: 前半 $(3t^2 - 18t + 15)$ は $f'(t)$、後半 $(t^3 - 9t^2 + 15t - 7)$ は $f(t)$ *)

$$
= (3t^2 - 18t + 15)x - 2t^3 + 9t^2 - 7
$$

# スライド2 ぞうげんひょうと せっせんの じょうけん

- ※ じつは こんかいの もんだいに、$y = x^3 - 9x^2 + 15x - 7$ の グラフは ふようだが…

(* 図: ぞうげんひょう *)

| $x$ | $\cdots$ | $1$ | $\cdots$ | $5$ | $\cdots$ |
|---|---|---|---|---|---|
| $f'(x)$ | $+$ | $0$ | $-$ | $0$ | $+$ |
| $f(x)$ | $\nearrow$ | きょくだい $0$ | $\searrow$ | きょくしょう $-32$ | $\nearrow$ |

- せってん $(t,\ f(t))$ に たいして、せっせん $y = (3t^2 - 18t + 15)x - 2t^3 + 9t^2 - 7$ が 1本 さだまる (1たい1にたいおう)
- $\Rightarrow$ A$(0,\ a)$ を とおる ような せっせんが なんぼん
  - (* 注: せってんが いくつ *)
- $(0,\ a)$ を とおる ような $t$ が 3つ もとまれば よい

# スライド3 $t$ の ほうていしきに きちゃくさせる

$$
y = (3t^2 - 18t + 15)x - 2t^3 + 9t^2 - 7
$$

- これが A$(0,\ a)$ を とおる とき、
- $a = -2t^3 + 9t^2 - 7 \quad \cdots (*)$ の 3じほうていしきに きちゃく
- (* 注: せってんが ことなれば せっせんも ことなる ので *)
- $t$ の ほうていしき $(*)$ の ことなる じっすうかいの かずが、じょうけんを みたす せっせんの ほんすう

- $g(t) = -2t^3 + 9t^2 - 7$ とすると、
- $g'(t) = -6t^2 + 18t = -6t(t - 3)$
- $g'(t) = 0$ の とき $t = 0,\ 3$ より、ぞうげんひょうは みぎの ように なる

(* 図: $g(t)$ の ぞうげんひょう *)

| $t$ | $\cdots$ | $0$ | $\cdots$ | $3$ | $\cdots$ |
|---|---|---|---|---|---|
| $g'(t)$ | $-$ | $0$ | $+$ | $0$ | $-$ |
| $g(t)$ | $\searrow$ | きょくしょう $-7$ | $\nearrow$ | きょくだい $20$ | $\searrow$ |

- よって、$y = g(t)$ の グラフは いか の ように なり、
- $(*)$ の ことなる じっすうかいの かずは、$y = g(t)$ と $y = a$ の こうてんの かずに ひとしく、
- これが 3こに なるのは ずより、$\boxed{-7 < a < 20}$
- (* 注: こんかい ほんとうに つかう グラフは こちら *)

# スライド4 おうようもんだい

**[れい]** $y = f(x)$ じょう の てん $(s,\ f(s))$ で せっする せっせんは、

$$
y = f'(s)(x - s) + f(s) = (3s^2 - 18s + 15)x - 2s^3 + 9s^2 - 7
$$

- これが $(X,\ Y)$ を とおる ような $s$ が 3つ そんざいする じょうけんを もとめたい
- $(X,\ Y)$ を だいにゅうして、

$$
Y = (3s^2 - 18s + 15)X - 2s^3 + 9s^2 - 7
$$

- せいりして、$2s^3 - (3X + 9)s^2 + 18Xs + (-15X + Y + 7) = 0$
- これで ことなる 3つの じっすうかい $s$ を もてば よい。
- $g(s) = 2s^3 - (3X + 9)s^2 + 18Xs + (-15X + Y + 7)$ と すれば、$X,\ Y$ は ていすうあつかいで あることに ちゅうい せよ。

$$
g'(s) = 6s^2 - 6(X + 3)s + 18X = 6(s - 3)(s - X)
$$

- $g'(s) = 0$ の とき、$s = 3,\ X$
- よって、$3$ と $X$ の だいしょうかんけいに より、ぞうげんひょうは つぎの ように なる。

# スライド5 ばあいわけ (i)(ii)(iii)

## (i) $X < 3$ の とき

| $s$ | $\cdots$ | $X$ | $\cdots$ | $3$ | $\cdots$ |
|---|---|---|---|---|---|
| $g'(s)$ | $+$ | $0$ | $-$ | $0$ | $+$ |
| $g(s)$ | $\nearrow$ | きょくだい | $\searrow$ | きょくしょう | $\nearrow$ |

(* 図: グラフ $y = g(s)$ の がいけい。きょくだいてん $(X,\ g(X))$、きょくしょうてん $(3,\ g(3))$ *)

- グラフの がいけい より、$g(s) = 0$ の ことなる じっすうかいが 3つ そんざいするのは
  - $g(3) < 0 < g(X)$

## (ii) $X = 3$ の とき

| $s$ | $\cdots$ | $3$ | $\cdots$ |
|---|---|---|---|
| $g'(s)$ | $+$ | $0$ | $+$ |
| $g(s)$ | $\nearrow$ | $0$ | $\nearrow$ |

(* 図: グラフ $y = g(s)$ の がいけい。へんきょくてん $(3,\ g(3))$ *)

- $g(s) = 0$ は、じっすうかいは $t$ じくとの こうてんが 1こ であるので、じょうけんを みたさない

## (iii) $3 < X$ の とき

| $s$ | $\cdots$ | $3$ | $\cdots$ | $X$ | $\cdots$ |
|---|---|---|---|---|---|
| $g'(s)$ | $+$ | $0$ | $-$ | $0$ | $+$ |
| $g(s)$ | $\nearrow$ | きょくだい | $\searrow$ | きょくしょう | $\nearrow$ |

(* 図: グラフ $y = g(s)$ の がいけい。きょくだいてん $(3,\ g(3))$、きょくしょうてん $(X,\ g(X))$ *)

- グラフの がいけい より、$g(s) = 0$ の ことなる じっすうかいが 3つ そんざいするのは
  - $g(X) < 0 < g(3)$

# スライド6 けつろん (りょういき)

- $g(3) = 12X - 20 + Y$
- $g(X) = -X^3 + 9X^2 - 15X + 7 + Y$
- である から、(i) $\sim$ (iii) より、

- $X < 3$ の とき: $12X - 20 + Y < 0 < -X^3 + 9X^2 - 15X + 7 + Y$
  - すなわち、$X^3 - 9X^2 + 15X - 7 < Y < -12X + 20$
  - (* 下線注: 左辺 $X^3 - 9X^2 + 15X - 7 = f(X)$ *)
- $3 < X$ の とき: $-X^3 + 9X^2 - 15X + 7 + Y < 0 < 12X - 20 + Y$
  - すなわち、$-12X + 20 < Y < X^3 - 9X^2 + 15X - 7$
  - (* 下線注: 右辺 $X^3 - 9X^2 + 15X - 7 = f(X)$ *)
- $X = 3$ の とき、じょうけんを みたす $(X,\ Y)$ は そんざいしない。

- この りょういきは ずの しゃせんぶ と する。(きょうかいせんを ふくまず)

- ※ $y = -12x + 20$ は きょくち の うえでの せっせん
