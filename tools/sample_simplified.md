# だい8かい せっせんの本数

- もんだい: $y = f(x)$ の せっせんを $(t, f(t))$ で たてる
- せっせんしき: $y = f'(t)(x - t) + f(t)$
- $f(x) = x^3 - 9x^2 + 15x - 7$
- $f'(x) = 3x^2 - 18x + 15$

---

# ぞうげんひょう

- $f'(x) = 0$ ならば $x = 1, 5$
- きょくだい $f(1) = 0$、きょくしょう $f(5) = -32$
- A$(0, a)$ を とおる せっせんが なんぼん?
- せってん $t$ が なんこ あるかと どうち

---

# 3じほうていしきに きちゃく

- $a = -2t^3 + 9t^2 - 7$
- $g(t) = -2t^3 + 9t^2 - 7$ とすると
- $g'(t) = -6t(t - 3)$
- $g'(t) = 0$ ならば $t = 0, 3$

---

# けつろん

- $g(0) = -7$、$g(3) = 20$
- せっせんが 3ぼんあるのは $-7 < a < 20$
- せっせんが 2ほんは $a = -7$ または $a = 20$
- せっせんが 1ぽんは それいがい
