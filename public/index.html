作成

Markdown から、手書き風のパワポを自動生成

見出しや箇条書き、数式を Markdown で書くだけ。あなたの筆跡を学習した文字で、 お手本のように一画ずつ描かれていくアニメーション付きスライド (.pptx) を作ります。

使ってみる
1

Markdown を書く

見出し・箇条書き・表・数式 ($\frac{1}{2}$ や $\int$ など) をそのまま記述。色や太字も指定できます。

2

プレビューで調整

レイアウトをその場で確認。文字や数式をドラッグで微調整でき、見たままが出力されます。

3

pptx を書き出す

クリックごとに手書き再生されるアニメーション付き .pptx をダウンロード。未登録の文字は登録へ案内します。
