m md-slides 作成 使ってみる

Markdown から、
整ったスライドを。

見出し・箇条書き・数式・化学式を Markdown で書くだけ。 その場でプレビューしながら微調整でき、編集できる .pptx として書き出せます。登録もログインも不要です。

作成をはじめる
無料・ブラウザだけで完結（教員向け・STEM 対応）
1

Markdown を書く

見出し・箇条書き・表・数式（$\frac{1}{2}$ や $\int$ など）・化学式（\ce{H2SO4}）をそのまま記述できます。

2

プレビューで調整

16:9 のスライドをその場で確認。要素をクリックして色・サイズ・フォント・登場アニメを微調整できます。

3

pptx を書き出す

そのまま編集できる .pptx をダウンロード。PowerPoint や Google スライドでも開けます。

md-slides — Markdown to editable slides
